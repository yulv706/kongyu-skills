# 配色角色配方库（Color Palette Roles）

> 来源：gzh-design-skill（isjiamu/gzh-design-skill）6 套公众号主题的配色体系提炼。原作者甲木×摸鱼小李，AGPL-3.0。本文件剥离了公众号平台约束（span leaf、禁 div/grid 等），只保留可迁移到任意前端场景的配色角色方法论与色板起点。

## 何时读

- 出方案选色时——给一个主色或一句气质描述，据此推导整套协调色板
- 审查配色是否花哨/塌陷——用五角色检查是否缺层或越界
- 多方向预览配色差异化——确认方向之间是色相轴差异而非同角色不同亮度

## 核心方法论：五角色配色结构

一套协调色板不是"选几个好看的颜色"，而是**固定角色分工**。每个角色有明确职责，缺了哪层都会出问题。

| 角色 | 职责 | 取色思路 |
|------|------|----------|
| 主色 accent | 编号、锚点强调、CTA、封面点睛 | 一个有辨识度的品牌色 |
| 浅底 / 浅边框 tint | 卡片背景、引用块、标签底 | 主色同色系的极浅色（主色 + 大量白） |
| 点睛高亮 highlight | 每段 1-2 处黄底 / 渐变高亮 | 与主色冷暖对比的第二色（绿配黄、红配橙） |
| 中性灰阶 neutral | 正文 / 标题 / 辅助 / 分割线 | 一套 5-7 级灰阶，承担 90% 的文字 |
| 下划线标记色 underline | 正文关键词逐段标记 | 主色的浅色版，温和不抢戏 |

铁律：灰阶承担正文阅读，色彩不参与正文阅读。彩色只在锚点（全文 ≤5 处）和标记层（每段 1-3 处）出现。大面积白底 + 灰阶，彩色只做点缀。

## 极简精确模式：允许折叠五角色（Surface Mode = `shell` / `workbench`）

Vercel 式开发者工具、工作台、设置页可以故意不用完整五角色。此时配色不是“缺层”，而是把角色压缩为：

| 角色 | 建议值（官方 Geist light，见 `vercel-precision-system.md`） | 职责 |
|------|--------|------|
| 灰阶阅读层 | 主文 `#171717` · 次文 `#4d4d4d` · 弱文 `#8f8f8f` · 面 `#ffffff` / `#fafafa` / `#f2f2f2` | 承担 95% 的文字、背景、边界；dark 用同 token 名不同值 |
| 交互 accent | light `#006bff`（blue-700）· dark `#006efe` | 链接、激活、单一主操作；不当装饰色 |
| focus 外环 | light `0 0 0 2px #fff, 0 0 0 4px #006bff` · dark `… #000, … #47a8ff` | `:focus-visible` 双环；不用旧的 `#005FCC` 手写 |
| 状态色 | red/amber/green 等官方 scale，默认小尺度 | 8–10px dot、细 badge、icon，不做大面积背景 |
| 边界色 | `gray-alpha-400`（light `#00000014`）或 gray-400 实心 | 优先半透明边 / shadow ring，不用随手灰 |

使用这个模式时，不强行添加 highlight、underline、第二主色。检查点从“角色是否齐全”改为“色彩是否只在语义处出现，灰阶是否足够支撑层级”。

## 克制三原则

1. 主色只在锚点出现（全文 ≤5 处），不到处铺
2. 大面积白底 + 灰阶，彩色只点缀
3. 一段内高亮 ≤2 种，不堆叠

## 从一个主色推导整套色板

只给一个主色或一句气质描述，按五角色推导：

1. 主色 → 你给的色
2. 浅底 → 主色 + 大量白（透明度 8-12% 叠白底，或直接取 HSL 降饱和加明度到 95%+）
3. 浅边框 → 主色 + 白（比浅底稍深，HSL 明度 90% 左右）
4. 点睛高亮 → 与主色冷暖对比的第二色（冷主色配暖黄、暖主色配冷蓝/绿）
5. 中性灰阶 → 固定 5-7 级：`#111827 → #374151 → #6B7280 → #9CA3AF → #D1D5DB → #F3F4F6`（Tailwind gray/zinc 体系，与主色色温对齐）
6. 下划线色 → 主色的浅色版（HSL 明度 85%+，饱和度降到 40-60%），border-bottom 2px

推导后检查可读对比度：浅底上的深字 ≥ 4.5:1（WCAG AA），主色在白底上 ≥ 4.5:1。

## 配色反模式（补充 ai-anti-patterns.md 的视觉禁令）

- ❌ 主色当背景大面积铺——主色只在锚点，背景交给白底 + 灰阶
- ❌ 多个角色用同一个色——五角色必须可区分，灰阶承担阅读、彩色承担强调
- ❌ 下划线色和主色同色同饱和——下划线要浅化降饱和，否则满篇都是刺眼的重色条
- ❌ 点睛高亮和主色同色系——失去冷暖对比就没点睛效果，绿配黄不是绿配浅绿
- ❌ 缺中性灰阶直接用主色当正文色——正文阅读不该有色彩偏向，灰阶是中性的
- ❌ 每段超过 2 种高亮——视觉噪音，失去焦点
- ❌ 全文超过 5 处主色锚点——到处都是重点等于没有重点
