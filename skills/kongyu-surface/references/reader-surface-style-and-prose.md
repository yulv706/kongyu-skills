# Reader Surface Style And Prose

适用：XiaoLab 自建页面的人类读者表层。

## 风格原则

- [ ] calm, plain, Chinese-first
- [ ] 少口号，少产品文案，少解释性大段落
- [ ] 结构清晰比视觉花样更重要
- [ ] 一屏内只允许一个主焦点

## 中文文案要求

- [ ] 标签短
- [ ] 动词直接
- [ ] 少英文混杂
- [ ] 不写教程腔流程说明，除非确实必要

## XiaoLab 壳层边界

- [ ] 统一 header / portal 导航是全站一致性的一部分；服务页内部不应随意发明第二套顶部导航语言
- [ ] XiaoLab 报告的颜色、字体、密度、圆角、logo 位置、目录导航、移动溢出和打印样式由本展示层决定。先核对当前 portal 的共享视觉 token，勿从写作源层复制一套固定配色。写作层传来 portal 返回链接和实际 logo 资产时，保留这一身份约束，同时避免重复的标题栏或装饰性徽章
- [ ] 长报告的目录要帮助定位判断与证据；读者需要比较的表格、公式和长标识符在目标视口与打印页中保持可读。具体布局由所选 surface 和实测结果决定

## 身份边界

- [ ] 除非用户明确要求，生成页面不默认添加打赏二维码、公众号关注、GitHub/X 浮条、乔木推荐入口或个人 Profile 区块
- [ ] 对外分享页面如需署名，最多使用低干扰页脚 `Powered by 向阳乔木` 链接到 `https://qiaomu.ai/`
- [ ] 正式多方向展示（非 Phase 2 风格试衣间）：每方向全宽沉浸带 + 独立工艺密度 ≥ 3 + 设计宣言入版面
