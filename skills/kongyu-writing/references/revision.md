# 改稿时先救人，再清句子

这份文件只在初稿完成以后读取。它不能参与第一稿生成。

改稿的目标不是把文章修到无懈可击。先保护已经活着的地方，再拆掉模型摆出来的姿势。

去 AI 味请求按三遍主流程组织改稿。第一遍理解材料、检查推进并拆掉表演性中文；第二遍复读词序、节奏和适用的语体约束，找出残留；第三遍修正残留、核验边界、检查结尾并交付。下面七个检查段是这三遍的详细拆分，不是额外增加的步骤。短稿完成三遍即可，长稿按七个检查段走完。诗歌、剧本、人物对白和实验写作执行事实或设定边界与用户明确要求；默认现代散文的标点和句式硬禁令不覆盖这些形式。不要为了让诗歌主干完整、让对白像说明文，改坏原本成立的作品。

## 先把“像 AI”与“本篇要改”分开

语料研究只能提供复核线索，不能把某个词、标点或句式单独判成 AI。破折号、设问、比喻和对举句在不同作者、模型和体裁里的分布差异很大。目标是去掉模板化和机械感，让文字像作者自己在处理一件事，不是保证任何检测器都无法识别，也不是为了检测器制造粗糙感。命中形状时，先看它是否让当前文章空转、机械或失去衔接；默认现代创意散文的硬禁令属于本 skill 的语体选择，不自动套到报告、学术、指定文体或有明确作者风格的文本上。

去 AI 味可以删减、合并和重排冗余句段，不制造新材料。保留影响判断的事实、条件和反证；不得凭空补数字、日期、因果、心理、引语、来源或场景，也不能把原文已有的具体事实改成“明显提升”“大量”“显著改善”一类的空泛概括。拿不准某项事实是否必要时，先核对它在论证中的作用。

## 研究参考的完整词法线索清单

下面覆盖本轮参考的完整 11 类可定位线索。它把夸大重要性、空洞动名词、广告语言、被动和幽灵主语、否定式排比、三段式、同义词轮换、格式噪音和聊天套话放回现有检查项中。它不是把词语逐个拉黑的机器黑名单。先判断体裁、作者风格和上下文，再看整句是否真的造成空转、机械、重复或衔接断裂。一个词单独出现，不足以成为改写理由。

1. **宏大框架与翻案腔**。把“具有里程碑意义”“反映更广泛趋势”“在持续演变的格局中”等夸大重要性的说法，改成具体事实、日期、数字和动作。也检查“不是……而是……”“并非……而是……”“不在于……而在于……”“与其说……不如说……”“表面……实际……”“看似……实则……”以及“你以为……其实……”等先制造误解、再强行翻转的写法。没有真实的误解与修正过程时，直接写判断和依据；确有自我修正时保留事实过程，不套固定句式。
2. **顿号密列、硬凑三段式和同义词轮换**。同一分句用多个顿号串起三项以上并列，或连续换几个名字说同一件事，读起来像清单或填表。改写时可合并、改变句法并固定称呼；法规条目、配置项、财务科目、必要列举、Markdown 列表和真正有层次的排比不改。
3. **相邻句结构同款**。相邻句反复使用相同骨架、逗号位置、成分顺序和收尾方式，导致节奏过齐。只打散确实机械的其中一句，短句和长句要有高低差；操作步骤、条款、对话、引语和有意排比不改。一段里平级案例明显在凑数时，可压缩主次，但不能删掉事实。
4. **揭晓式破折号与格式噪音**。适用的默认现代创意散文在第五遍按本 skill 的语体约束检查；其他文体只处理用破折号制造普通判断的停顿、揭晓或空泛补充。不要主动添加黑点、表情、全大写标题、标题内撇号或 README 式数字编号。范围、解释、对话、格式要求和作者本来就稳定使用的标点不因一个符号单独改掉。
5. **提示性或空转冒号与路标**。处理“核心是”“关键在于”“原因如下”“一句话总结”“换句话说”等本身不增加信息的提示语，以及只宣布下面有列表、删掉前句也不损失信息的空转句。真正承接上文、引出必要说明、人物原话、小标题、列表内部、网址、代码和报告结构中的冒号保留。
6. **序数词小标题**。小标题连续使用“一、二、三”或“第一、第二”给全文编号，却没有提供章节含义时，删掉编号、保留标题文字。步骤、时间线、法规条款、正文里的“首先……其次”和 Markdown 有序列表不改。
7. **广告语言、模糊归因与理想化拟人**。删掉“植根于”“充满活力”“革命性”“无与伦比”等只负责抬价的词，也删掉没有来源的“专家认为”“多个来源指出”。工具、系统或流程被写成“智慧的导师”“永不疲倦的助手”“贴身的秘书”“全能的顾问”等理想化职业人格，只承担夸赞而没有解释机制时，改写为它实际做了什么。具体人物喻体、文学性表达和确实带来新理解的比喻不改。
8. **空洞动名词与具体信息被概括覆盖**。把“突出、反映、促进、证明、确保”等只制造深度的尾巴改成可核实的事实或直接动词；同段或相邻段已经出现数字、时间、对象或事实，后面却用“显著提升”“大幅增长”“大量”“完成了优化”等空泛说法重新盖住它。恢复原文已有的具体信息或直接恢复动词；原文没有的数字、事实和细节一律不能补。
9. **空泛起手式与聊天机器人套话**。把“说白了”“说穿了”“先说结论”“希望对你有帮助”“很棒的问题”“总而言之”“期待你的回复”等当成姿态、收尾或礼貌时，删掉或改写。它们在原话、人物口吻或确有语义作用时，按上下文处理；没有真实不确定性时也不要用“可能”反复留退路。
10. **五种译文句式、空泛系动词与幽灵主语**。只检查以下五类，不凭语感扩大范围：过长前置定语；“当……时”前置完整从句；“对于……来说”“对……而言”“就……而言”“关于……”“在……方面”等前置话题壳；“然而”“因此”“此外”“与此同时”“换言之”“总而言之”等空泛句首路标；“这意味着”“这表明”“这说明”“换句话说”重复前句的复述句。优先写清主语和动作，减少“充当、构成、代表、被视为”等空泛系动词和被动语态。需要明确范围、转折、因果或专业固定表达时保留；名词化、长句本身不是翻译腔理由。
11. **段首零回指评论**。非首段直接以“听起来”“看起来”“说白了”“值得注意的是”“更重要的是”“关键在于”“问题在于”“意味着”“不难看出”等评论语开头，却没有“这／那／其／此”等回指上文的成分。补回指词、点明评论对象或重写承接；首段、已有回指、对话和引语内部不改。独立成段的比喻也不能只因起段突兀就删掉。

这份词法清单只用于局部措辞检查。命中形态但不影响表达时不改；没有命中也不等于句段必须保留。句段的删留与重组按下文“第二遍”判断，不以命中某个词形为前提。

## 第一遍看谁在说

读完以后回答四件事。

- 现实稿的作者凭什么知道这件事，虚构稿的叙述者此刻能够知道什么。
- 哪一处能看出他真的在意。
- 哪个判断有材料托着，哪个情绪有动作或关系托着，哪些真实的矛盾、限制和细微差别不能被磨平。
- 哪几段换一个模型也能原样写出来。

第四类段落优先处理。现实稿补信息来路、作者取舍和具体材料，虚构稿补叙述位置、人物行动和场景变化。没有东西可补就删。

有样本时，先对照它的句长、词汇、标点、惯用表达和思维节奏，再修正语气。复现作者自己的写法，不套一套通用的“真人腔”。不要用增加“我觉得”“说真的”“大家想想”修复匿名感。声音来自取舍，不来自代词；第一人称只在作者确实拥有这段经验或判断时使用。

## 第二遍看文章怎样往前走

先试删，再改措辞。删去解释或评论句段后，若事实、因果、必要限定与阅读体验都没有受损，就删掉，不替它寻找更自然或更漂亮的说法。分析应增加读者尚未得到的联系、解释或反证；原话已经传出的意思，不必再翻译一遍。

只用来评价前文、预告分析或证明作者谨慎的旁白，删除。严谨、证据边界和反例要求先落实在判断的范围与措辞中，不逐段展示成“这说明什么／不能证明什么”。会改变结论或防止具体误读的限定仍须保留；用户要方法讲解、审稿意见，或读者确实需要步骤导航时，也保留相应说明。

连续几段重复“材料→释义→保留意见→小结”时，重新选择主材料，合并重复判断，让后续材料负责推进或反驳。完整阅读不等于逐项写入，反例也不必平均分配给每段。用户再次指出同类问题时，从段落取舍重改，不沿原提纲逐句换词。

虚构改稿例：“他把报名表推回来，说‘我还要想想’。这说明他还没有确定，原话已经足够清楚。”只留前句即可。“报名人数增加了，但统计周期也延长了一周，尚不能比较报名速度。”中的限定会改变判断，应保留。

现实稿给每段写一个不公开的材料出处，可以是用户材料、公开来源或可核验流程。虚构稿改为标出这一段由哪个人物目标、动作、发现或关系变化托住，不给创造出来的细节伪造来源。只能写出“这是进一步解释”或“这是可能的影响”，说明这一段没有新东西。删到文章长度与材料相称，不替目标字数保稿。

遇到历史、技术、制度和数据，问它正在回答哪一个问题。删掉以后人物选择、风险和判断都不变，这段知识来早了，或者根本不用来。

做一次压缩试验。若删掉三分之一以后事实、动作、判断和阅读体验几乎没变，原稿就是在注水。保留删短后的版本。

人物稿看他在哪里，做了什么，遇到什么限制，后来怎样。虚构稿看谁想得到什么，场景结束时什么变了。

整篇靠“第一层”“另一层”“更深处”推进时，把这些路标删掉。让事实差异与读者问题承担连接。

## 第三遍拆掉表演性中文

### 假深刻

圈出所有单独截图很好看、放回正文却没有增加事实、解释或情绪的句子。大部分删掉。

连续几段都用一句短判断收尾，留下最有材料的一处。普通段落回到普通句子。

### 假具体

搜索精确时间、天气、神态、房间摆设、烟酒食物和突然出现的原话。现实稿逐项问它来自哪里，会不会改变后文。虚构稿只问它是否属于当前视角，是否影响行动、关系或气氛。

现实稿没有来源也没有作用，删掉。虚构稿没有作用，删掉。不要让装饰细节冒充亲历，也不要让虚构细节变成统一摆放的道具。

### 假口语

“老铁”“兄弟们”“咱就是说”“泡杯茶慢慢说”一类称呼只有当前说话者或人物真会这样说时才留。

不要为了制造活人感主动添加粗口、错别字、三连省略号和括号吐槽。人物身份、实验写作或原始材料确实需要时，按作品本身处理。

### 抽象名词

抽象名词连续出现时，问清谁做了什么，影响了谁，钱、时间和责任落在哪里。

一句话能换进十篇商业文章，说明它没有当前材料。

### 比喻换场

现代现实散文先把借来的世界写在旁边。道路、战争、建筑、温度、仓储、海洋、身体。

短距离出现三套时先全部还原成本义。本义已经清楚，一个也不用放回。小说、诗歌和抒情写作改看意象是否属于同一套感受与场景，不按数量机械删除。

抽象产品稿尤其容易借用仓库、抽屉、温度、死亡、坍塌、浪潮、钥匙和底座。所写对象并非这些东西时，先删掉。删掉以后意思没损失，就不要换一个新比喻。

## 第四遍听一遍中文顺不顺

这一遍检查现代散文。诗歌分行、人物对白和剧本动作可以使用省略、断句与不完整句，按 `references/formats.md` 和 `references/fiction.md` 判断。

### 主干早点来

圈出“……的，是……”“更……的是”“真正让……的”“那些……的……”和一句里多个“的”。

先找到做事的人，把他与动作放到前面。原因、时间、条件与例子接到后面。

不要机械切短。连续短句会变成鼓点。复杂关系允许用长句讲完，只要主干早点出现。

段落也要有高低差。连续十段都只有一句话，合并其中能顺着读下去的部分。连续几段长度接近，检查是不是每段都按同一模具完成。

### 前一句把什么交给了后一句

顺着每个逗号和句号往后看。后一句接的是前一句刚出现的人、物、动作或结果，通常会顺。它忽然换对象，却只靠“这”“它”“他们”连接，读者可能会认错人。

指向清楚时，删掉重复的主语和机械连接词。两个人同时在场、前一句出现多个名词或中间插入一大段话时，把名字写回来。

长定语尽量拆开。先让人和东西出现，再补它的来历、条件和限制。连续出现三个“的”，或者读到名词时已经忘了句首，就要重写。

### 段首也要有回指

新段落如果直接写“这说明”“听起来”“值得注意的是”一类评价，先问评价对象在上文哪里。对象不清，就补回指词、把评价对象写出来，或重写承接；不要只加一个连接词掩盖跳跃。段首连接词的总量不是问题，缺少明确指向才是。

### 停顿有轻重

读出声。逗号处应当还能接着说，句号处应当已经落下一件事。连续短句像敲桌子就合并，长句一口气没有落脚处就拆开。

短句放在长句后面，确实能压住一句话。每段都这样收尾，会变成模型的固定鼓点。让普通地方普通地结束。

### 动作后面少解释一句

圈出动作、物件、原话和比喻后面的情绪解释。读者已经能看见人物在犹豫、害怕、舍不得或嘴硬，就删掉解释。

留白只省读者能够自己得到的部分。关键事实、因果、人物选择和必要条件仍要说清。

### 白话与古意别打架

检查“买／购买”“改／修改”“看／观察”“用／使用”这类单双音节词。根据说话者和场合选，不要全换成正式长词，也不要为了古意全压成单字。

成语、典故和文言句单独拿出来读。删掉以后更自然，就删。需要紧跟白话解释，也删。它与人物身份、题材和全文语气不在一起，更要删。

## 第五遍检查适用散文的语体约束

对默认现代创意散文中作者可改写的文字，搜索中文冒号、英文冒号、破折号和连接号式破折号并按本 skill 的语体约束处理。网址、代码、机器字段和经核实需逐字保留的引语不改；剧本、对白、诗歌及用户指定的既有语体不按这组标点清零。

搜索“不是……而是……”、“并非……而是……”、“不在于……而在于……”、“与其说……不如说……”、“不只……还……”、“不只……也……”、“表面……实际……”、“看似……实则……”及其变形。拆回事实陈述。

搜索“不丢”“说白了”“说穿了”“先说结论”。全部删除或改写。

检查模型常用的洞察路标。“更微妙的是”、“还有一层”、“只说对了一半”、“值得注意的是”、“需要指出的是”、“从某种意义上说”用来给段落抬高时删除。文字确实在说楼层、数量或原句本义时保留。

下面这些词只提示回到语境核查：赋能、抓手、商业闭环、价值闭环、闭环、能力沉淀、打法、拉通、底层逻辑、顶层设计、认知跃迁、价值释放、能力建设、降本增效、内容矩阵、全链路、组合拳、打开想象空间、想象空间、结构性机会、关键命题、深层逻辑、技术底座、公共底座、技术主权、单点风险、主脊柱、材料锚点、认知增量、迭代闭环。词语只负责抬价时改成人、动作、时间与后果；“闭环控制”等有明确专业本义的名称保留。

下面这些词只做语境检查。沉淀、颗粒度、对齐、协同、链路、生态位、心智、范式、方法论、核心变量，以及“关键、核心、必不可少、深入、突出、支撑、促进、全景、见证、动态、发挥、错综复杂、此外、同样地”等高频词。它们确实表示化学沉淀、排版对齐、生态学概念、学术概念或其他不可替代的本义时保留；只是在给普通事情抬价时改写。中文里的“是”也不是禁词，只在空泛定义或套话里处理。

检查脚本里的强制项必须与本节适用范围一致；需要看专业本义的词只作人工提醒，不能让脚本凭子串硬判失败。

经核实且需要逐字保留的原话按原样引用。适用散文里确实命中的语体禁令要改，但不为清零而改坏事实、术语或引语。

## 第六遍核现实或设定

现实稿核时间、数字、身份、引语、因果与第一人称动作。核验说明留在后台。

虚构稿核人物知道什么、时间空间、伤势物件与世界规则。情绪已经由动作托住，删掉紧随其后的解释。

混合稿核现实中必须准确的部分与创作空间有没有彼此冒名。

## 第七遍查结尾

把最后两段分别删掉再读。删掉更有力，就让文章提前结束。

最后一段重新概括全文，即使概括得很漂亮，也先删掉。前文已经讲明白的内容不需要再证明一次。

搜索“时代、文明、未来、世界、历史、奇迹、所有人、全人类”。正文没有持续处理这个尺度，结尾回到具体事实、人物动作或当前判断。

开头物件在结尾回来时，确认读者对它的理解已经改变。含义没变，不必回来打卡。

## 使用检查脚本

长稿保存为文本或 Markdown 后运行下面的命令。

```text
python3 scripts/check_prose.py 稿件.md
```

默认散文模式下，脚本把适用的冒号、破折号、明确翻案句、硬停词、明确黑话和模型路标判为失败。翻案腔变形、三项以上同构排比、名词化、连词密度、句长变异、「」金句密度和抒情词只列为提醒。其他形式运行 `python3 scripts/check_prose.py --mode contextual 稿件.md` 时，所有形状只供人工复核，不以退出码阻断交稿。

脚本只负责发现形状，不能判断文章有没有人，也不能判断引语来源或专业术语是否必要。警告项需要回到材料与说话位置人工判断；诗歌、剧本、对白、技术解读和保留原话的稿件不用默认散文的硬失败作交付门。

哪里让我相信作者确实知道这件事。

哪里让我愿意继续读。

哪一段像人在处理一个问题，哪一段像模型在完成写作任务。

哪句话说得比材料大。

文章在哪一句已经结束。
