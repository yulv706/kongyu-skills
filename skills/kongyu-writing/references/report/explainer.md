# 知识讲解与概念学习

适用：讲解一个陌生主题、教程的概念部分、知识综述。读者要知道：这些对象是什么，它们之间有什么关系，能不能复述或应用。

通用原则见 `SKILL.md` 报告模式。

读者说“小白”“零基础”“第一次接触”，或指出呈现没有循序渐进时，先按下面的依赖顺序重排，再写正文。

## 先定读者能做什么

写之前写下三件事：读者读完应能回答的一个问题；涉及的对象，各自接收什么、产出什么；哪些对象之间的关系还没有被材料讲清。

## 依赖顺序

- 不熟悉的主题，先用普通语言说明“这是什么”。只有结构、流程或关系用图更容易理解时才加图。

- 先讲前提，再讲用到前提的主张。
- 一段只引入一个新概念。第二个新词放到下一段。
- 名词第一次需要时才引入，不先列术语表。
- 每个数字放在读者已经知道它测什么的地方之后。

示例：

- 差：“校准误差是一种衡量把握与实际正确率差距的指标，越低越好。”然后下一段马上用“拆分模块的校准误差”。（读者还没见过拆分模块。）
- 好：先讲模型对选项打分、把分数变成把握，再讲“把握说得准不准”，最后用“校准误差”命名它。

## 用一个真实例子贯穿

- 例子取自材料，给出原文或输入。
- 多种情形分条编号，每条写条件、结果和数字。
- 例子末句说明它说明什么。
- 没有材料里的例子，就用明确标注为假设的数字，并声明它不是研究证据。

## 图和动画

- 图的对象和关系要标清，同一个对象在多张图里用同一个标注。
- 交互或动画要让读者能预测、能改变一个变量并看见结果。
- 图里的数字必须与正文一致；模拟的参数须注明是示例值。

## 选择表达形式

先问读者要克服的障碍，再选最小的形式：

| 读者的障碍 | 形式 |
| --- | --- |
| 一个事实或一步操作 | 短文、命令或小表 |
| 对象之间的关系或流程 | 标注清楚的结构图 |
| 不知道变量改变会怎样 | 可调节的图或小型交互页 |
| 依赖先后的变化 | 分步的动画或分步图 |
| 公式和精确推导 | 技术文档，必要时用 TeX |

## 验收

- 读者复述一遍，指出第一个接不上的前提。修复后再测。
- 读者能用例子之外的一个新情形，说出结论。

## 结尾

有来源支撑的结论，附出处。知识综述里未解决的问题放结尾，和已确立的结论分开。
