# 跨文体示例：拒收样例与句子对照

各文体 ref 的规则在这里有具体的差与好。拿不准时先看这里。

## 拒收样例

下面的失败在各类报告里都出现过。出现任何一种，就地重写，不交付。

| 失败 | 表现 | 改法 |
| --- | --- | --- |
| 摘要躲着说 | 只复述目标和步骤，没有结果 | 第一屏写发现句 |
| 表头暗号 | “登记”“窜改”“配置 A/B” | 写测量什么、单位或分母 |
| 目录混杂 | 问题、步骤、查证进度同在目录 | 目录用读者的问题或有证据的结论 |
| 编造例子 | 用像真的场景、模型行为或数字举例 | 核对材料；没有真实例子就不举例 |
| 防御声明 | 每节重复“本文不主张……” | 限制贴着结果写一次 |
| 追加更新 | 新结果以“更新”段追加 | 整体重写 |
| 子集冒充全集 | 只列部分材料，读者以为是全部 | 写明总数、分组、覆盖程度 |
| 内部标签泄漏 | K1、S3、B2b、ICE 出现在正文 | 译成研究对象或动作 |
| 首段先抛结论 | 第一句就给结论，读者不知道比较对象 | 先写问题，再写做法，最后写结果 |
| 首段一句塞多件事 | 一句里同时有方法、基线和结论 | 一句一件事 |
| 没有可抓的重点 | 全文只有小标题加粗，结论埋在段落中间 | 首屏加粗核心发现和决定，数字不加粗 |
| 数字没对象 | “从 0.023 升到 0.282” | 同一句写对象和比较对象 |
| 衔接跳步 | 从结果直接跳到结论 | 补出中间一步 |
| 关系只用文字 | 步骤或组件的关系要读者自己在段落里拼 | 画流程图或结构图，框写标准名称，箭头写传递的内容 |
| 装饰图 | 图只为好看，不承载关系或比较 | 删掉，或改成承载比较的图 |
| 只有表和字 | 读者要自己在数字里找差别 | 补一张结果图 |
| 图不承载比较 | 装饰图，图注只写“图 1” | 对象和对照同图，图标题写结论 |
| 首屏指向首屏外 | “见第六节”“下一节” | 首屏内讲清 |
| 整页难扫 | 一屏全是长段，没有分行 | 段落短，并列用列表，比较用表 |
| 图注带路径 | 图注写 `docs/…md` | 路径放附录，图注写口径 |
| 例子读者走不通 | 只写“B 换成 D”，没有题目和原文 | 给题目、选项、原文，情形分条带数字 |
| 一次给太多新词 | 一段里两个以上未讲过的术语 | 一段一个新概念 |
| 同量两数 | 同一指标两个数，没说明差别 | 同处写明口径，或只留一个 |
| 决定没有来路 | 只列结果就给建议 | 建议前用一句“因此”连接 |
| 内部称呼泄漏 | 正文出现“师兄”“用户”“AI 决定” | 换成读者认得的角色 |
| 重训经过占主线 | 第二次训练、事后追加一节接一节 | 一句话说设置变了结论是否一致 |
| 限制三处重复 | 同一限制在结果旁、边界节、附录各写一遍 | 写在结果旁，其余只指向 |
| 输入冒充输出 | 只有题目，却补出模型怎样回答 | 只写实际有的输出 |

## 中文句子：常见毛病与改法

来源：余光中《怎样改进英式中文？》（《明报月刊》1987 年 10 月）的例句，以及叶圣陶《谈文章的修改》的修改方法。

- **弱动词加抽象名词。** 差：“对社会作出了重大的贡献。” 好：“对社会贡献很大。”
- **抽象名词做主语。** 差：“他的收入的减少改变了他的生活方式。” 好：“他因为收入减少而改变生活方式。”
- **空泛的“可读性”类名词。** 差：“这本传记的可读性很高。” 好：“这本传记很好看。”（指标名如“校准误差”是真术语，保留并讲清。）
- **连续的“的”。** 差：“灰暗的凄冷的天空。” 好：“灰暗而凄冷的天空。”
- **长定语前置。** 差：“我见到一个长得像你兄弟说话也有点像他的陌生男人。” 好：“我见到一个陌生男人，长得像你兄弟，说话也有点像他。”
- **空的连接词和副词。** “成功地发明”“竹林七贤之一”“关于……”，去掉意思不变就去掉。
- **能主动就不被动。** 差：“新大陆被发现了。” 好：“哥伦布发现了新大陆。”（施动者不清楚时保留被动。）

叶圣陶的修改方法：先想清这一段读者要带走什么，再改字；一个毛病想出两三个改法，比较后选最好的；改完念几遍，不顺的地方会自己露出来。
